Criptografia

Escreva uma mensagem e veja ela virar um texto que ninguém lê. Primeiro com as cifras antigas, que se quebram em segundos. Depois com o Fernet, que é o que este site usa de verdade para guardar seus dados.

César e Vigenère são só para aprender

Essas cifras têm centenas de anos e não são seguras: a de César tem só 25 chaves e a de Vigenère cai com análise de frequência. Nunca use nenhuma delas para proteger dados de verdade, e nunca invente o seu próprio algoritmo para isso.

Os dados reais do CT (contato e mensagem do pedido, telefone do cadastro) são guardados com Fernet: AES-128 no modo CBC mais uma assinatura HMAC-SHA256, de uma biblioteca auditada. A demonstração do Fernet abaixo usa uma chave própria, temporária, que não abre nenhum dado real.

Cada letra anda k casas no alfabeto. Com k = 3, A vira D, B vira E e Z volta para C. Letras com acento andam pela letra base e mantêm o acento; números, espaços e emojis ficam como estão.

Texto cifrado

Uma César com várias chaves: cada letra da palavra-chave diz quanto andar (A = 0, B = 1, ... Z = 25), e a palavra se repete pelo texto. Por isso a mesma letra pode virar letras diferentes. Ainda assim, ela é quebrada com estatística desde o século XIX.

Texto cifrado

O Fernet junta duas peças: o AES-128-CBC esconde o conteúdo e o HMAC-SHA256 assina o token. Se alguém mudar um único bit, a assinatura não confere e o token inteiro é recusado. Sem a chave, o token não revela nada além do tamanho aproximado e da hora em que foi criado.
